# « base » : avant | après (26 oct.)

Décision du fondateur : « on remplace, mobile aussi ». Plus de « base » pour nos installations ni pour notre monde, sur le téléphone, le web et dans les textes du Core. Le mot reste pour une base ennemie (le Cafard, un lieutenant). Lignes écrites par la plume (docs/TON.md), puis relues par un relecteur adverse : 18 lignes corrigées ou refaites, puis intégrées à la source commune.
